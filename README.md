# resume-generator

A python tool for generating resumes from YAML data and rendering them to accessible (machine parsable) PDFs.
Currently, the data structure available is fixed, but the Jinja templates and CSS can be customized.

## Development

### Installation

First install the required dependencies:

```bash
uv sync
```

Then install the package in editable mode, which allows you to make changes to the code and have them reflected without needing to reinstall the package. `resumegen` will be available as a command-line tool after installation.

```bash
pip install . -e
```
